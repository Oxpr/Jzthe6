# Jzthe6

A small Python task manager that lets you add, list, complete, and delete tasks from the command line.

## Usage

```bash
python3 task_manager.py add "Buy milk"
python3 task_manager.py list
python3 task_manager.py complete 1
python3 task_manager.py delete 1
```

## Notes

- Tasks are stored in `tasks.json`.
- The script creates the file automatically if it does not exist.
